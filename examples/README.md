# Example templates

Copy what you need into the `templates/` folder of your site and replace the handle `team` with the handle of your
calendar.

| File | What it shows |
| --- | --- |
| [`upcoming.twig`](upcoming.twig) | The next events as a list, grouped by day, with a link to subscribe |
| [`month.twig`](month.twig) | A month view with a table, the previous and the next month |
| [`fullcalendar.twig`](fullcalendar.twig) | [FullCalendar](https://fullcalendar.io/) fed by the JSON feed of a calendar |
| [`entries.twig`](entries.twig) | The same events as entries of the example section «Calendar events» |
| [`event.twig`](event.twig) | One event with «add to calendar» links and structured data for search engines |
